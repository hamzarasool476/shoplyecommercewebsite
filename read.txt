🛍️ Shoply — Modern E-Commerce Website

Shoply is a modern, responsive e-commerce website built using HTML, CSS, and JavaScript. It provides a clean shopping experience with product categories, product search, and a functional shopping cart.

✨ Features
🏠 Modern homepage with hero section
🛍️ Product listing
🔎 Product search
🏷️ Category filtering
🛒 Add products to cart
❌ Remove products from cart
💰 Automatic cart total calculation
📱 Fully responsive design
📦 Checkout button
🎨 Clean and modern UI
⚡ No external frameworks required
📁 Project Structure
shoply/
│
├── index.html

🚀 Getting Started
1. Download or Clone the Project

Download the project files or clone the repository.

git clone https://github.com/your-username/shoply.git

2. Open the Project

Navigate to the project folder:

cd shoply

3. Run the Website

Simply open:

index.html


in your web browser.

No server or installation is required.

🛒 How to Use
Browse the available products.
Use the category cards to filter products.
Use the search box to find products.
Click Add to Cart to add an item.
Open the cart using the cart button.
Remove products if needed.
Click Proceed to Checkout.

The current checkout is a front-end demo and does not process real payments.
